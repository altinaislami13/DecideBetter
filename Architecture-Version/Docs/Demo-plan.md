# 🎯 Demo Plan — DecideBetter

## 1. Project Title
DecideBetter — Multi-Criteria Decision Support System

---

## 2. Problem It Solves
People often struggle to make important decisions (e.g., choosing a job, university, or product) because:

- Too many factors to consider
- Decisions are based on emotions, not logic
- Lack of clear comparison between options

DecideWise solves this by providing a structured, data-driven way to evaluate and compare options using weighted criteria.

---

## 3. Target Users
The system is designed for:

- Students choosing universities or careers
- Professionals comparing job offers
- Individuals making personal decisions (e.g., buying a laptop, moving city)
- Anyone who wants to make better, rational decisions

---

## 4. Demo Flow (Main Flow)
### Selected Flow:
Create Decision → Add Criteria → Assign Weights → Add Options → Calculate Results → View Recommendation

### Why this flow?
This is the core value of the application because it demonstrates:

- User interaction
- Core algorithm (Weighted Sum Model)
- Real-time result generation
- Practical usefulness

---

## 5. Real Problem Solved

### Problem:
Users cannot objectively compare multiple options with different importance levels.

### Where it occurred:
During decision-making processes (e.g., choosing between job offers or universities).

### Solution:
Implemented a **Weighted Sum Model (WSM)**:

Score = Σ (weight × value)

This allows:
- Fair comparison
- Transparent logic
- Clear final recommendation
